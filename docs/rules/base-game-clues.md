# Base-game Clue tokens

The user-supplied `source-assets/clues/Images (2).rar` contains 36 individual 512×512 scans. Each scan shows its location-bearing face above the shared magnifying-glass back. A visual contact-sheet audit verified exactly one face for every board location: the 21 numbered spaces and 15 named locations. The archive SHA-256 is `e8c4a62aac0fbab33aa2f3393ab4b32ab033bcad7e780a7177b49407b9a895fc`.

`packages/content/src/clues.ts` owns the 36 physical token IDs and their board locations. `pnpm clues:generate` reproduces the cropped WebP faces and shared back under `apps/web/public/tokens/clues`; it refuses a changed archive until the mapping is rechecked. Setup shuffles those physical IDs into a server-private pool and reserves investigators' starting Clue tokens from it, so no extra copies are created. An internal spawn transition draws a physical token, optionally places it on a specified space instead of its printed space, and publishes only an opaque board marker. It recycles and randomizes the discard pile when the pool is empty. Internal gain and encounter-collection transitions now move real tokens into private holdings, with gain bounded by available components; collection requires an investigator at the marker's space. Test rerolls move a physical Clue to the discard pile, accepted trades move physical Clues between private holdings, and defeat sets aside held physical Clues with the defeated investigator's sheet. Condition gain/discard effects, defeated-investigator encounters, Mythos icon wiring, encounter-phase invocation, and board UI presentation remain pending. Undrawn, held, and on-board token identities remain server-private.

The executable Delusions reverse returns discarded physical Clues to the faceup discard pile, including any Clue spent for a test reroll before the reverse resolves. Other Condition effects still need physical-token integration.

The Visions of Hypnos Blessed reverse now draws up to two physical Clues from the private pool/discard rather than increasing only a numeric counter. It respects the finite component supply. Other gain effects still need connection to the same internal transition.

Replacing a defeated investigator now draws their starting Clues from the remaining private pool, recycling and shuffling the discard pile if needed. Physical Clues on the defeated investigator's sheet stay set aside; replacement never duplicates them. A shortage grants only the available tokens.

The web client now reads the room's public opaque board markers and draws the common Clue back near each marked location. The location inspector shows the count. Physical face IDs remain private; the markers do not yet offer an encounter command.

An internal Mythos Clue-icon transition now reads the revealed card's verified icon and the player-count reference card, spawns that many Clues atomically (up to the physical component limit), and records that this card's Clue icon resolved so a retry cannot spawn duplicates. It is not exposed as a standalone client action: the shared Mythos sequencer must enforce preceding icons and invoke it at the printed position.
