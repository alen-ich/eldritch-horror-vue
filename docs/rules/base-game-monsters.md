# Base-game Monster spawning

The server-private Monster cup supports a deterministic internal draw-and-place transition. It consumes one physical normal token, creates a distinct on-board instance, and publishes the resulting location without exposing cup order. Six printed spawn effects that move a Monster to a named space are represented as typed destinations. Wraith's printed instruction makes the Lead Investigator gain Cursed through the existing Condition lifecycle; an existing Blessed Condition cancels it, and an exhausted Cursed supply cannot prevent the Monster itself from spawning. Empty Monster cups and unknown spawn effects do not mutate game state. Gate opening and the internal green Mythos Monster Surge step now invoke this transition.
The green Mythos Monster Surge icon now invokes this transition at each active Gate matching the current Omen, using the player-count Reference card. If none match, it opens one Gate instead. This remains an internal engine step until the live Mythos phase is wired.

Named Deep One and Star Spawn ambushes within supported Research now reference the catalog attributes without drawing, spawning, damaging or returning any physical Monster token (Reference Guide page 2). Separate Will/Strength tests support owner-only Clue rerolls and serializable continuation. Investigator defeat interrupts further combat/card effects; defeating the ambush does not unlock another encounter. The parent Research card resumes its printed branch and then ends the seat's encounter. Star Spawn uses its printed -1/3 Horror, -3/3 Damage and toughness 5; its Reckoning is not triggered. This is not random ambush sourcing or general board-combat reroll support; Cultists and possession bonuses remain pending.

During the Encounter phase, the active investigator can now send a `FIGHT_MONSTER` intent for an on-space Monster instance. The server rolls dice and applies the existing combat/defeat transition. It records fought instance IDs for this investigator's encounter, disallows fighting one twice, and blocks location decks while any Monster remains. If every Monster on the space has been fought and at least one survives, the encounter passes to the next investigator; if all are defeated, a location encounter is available. A combat defeat enters the existing defeat choice and then advances the encounter seat. Unsupported Monster text and untyped possession combat effects still stop before any roll or state mutation; this is not full Monster combat coverage.
